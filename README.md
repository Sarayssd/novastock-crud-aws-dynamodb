# 📦 NovaStock – Sistema de Gestión de Inventario

Aplicación web CRUD para gestión de inventario de productos, desarrollada con **Python Flask** y **Amazon DynamoDB**.

---

## 🚀 Tecnologías

| Capa       | Tecnología               |
|------------|--------------------------|
| Backend    | Python 3.10+, Flask 3    |
| Base datos | Amazon DynamoDB (Boto3)  |
| Frontend   | HTML5, CSS3, JavaScript  |
| Configuración | python-dotenv          |
